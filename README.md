# React + Vite + Tailwind CSS + Firebase

🚧 **Este projeto ainda está em desenvolvimento.** Algumas funcionalidades e componentes podem passar por mudanças ou ainda não estar finalizados.

Este projeto é um **site de cardápios online**, construído com **React**, **Vite**, **Tailwind CSS** e **Firebase**, com interface responsiva para clientes e um painel administrativo completo. A estilização foi feita com **Tailwind CSS**, permitindo interfaces limpas, responsivas e altamente personalizáveis usando classes utilitárias. O **Firebase** fornece autenticação segura e armazenamento em tempo real para os produtos.

No **painel do cliente**, é possível:  
- Navegar pelos cardápios  
- Visualizar produtos disponíveis, categorias e detalhes de cada item  
- Filtrar produtos por **categoria**  
- Visualizar a localização de cada estabelecimento ou produto  

Na **área administrativa**, os administradores podem:  
- Realizar **CRUD completo** nos produtos (criar, ler, atualizar e deletar)  
- Gerenciar produtos cadastrados por clientes ou usuários  
- Acompanhar alterações e atualizações em tempo real  

## 🔧 Tecnologias Utilizadas

- [React](https://react.dev/) — Biblioteca para construção de interfaces de usuário baseadas em componentes  
- [Vite](https://vitejs.dev/) — Ferramenta de build ultrarrápida com suporte nativo a ESModules e HMR  
- [Tailwind CSS](https://tailwindcss.com/) — Framework utilitário de CSS para desenvolvimento ágil e consistente  
- [Firebase](https://firebase.google.com/) — Autenticação de usuários, banco de dados em tempo real e hospedagem  
- [Node.js](https://nodejs.org/) — Backend para gerenciamento de produtos e integração com Cloudinary  
- [Cloudinary](https://cloudinary.com/) — Armazenamento e gerenciamento de imagens
